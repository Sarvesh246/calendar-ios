# Security

If you find a vulnerability, please report it privately through GitHub's
[private vulnerability reporting](https://github.com/Sarvesh246/calendar-ios/security/advisories/new)
rather than opening a public issue. Expect a first reply within a few days.

In scope: the native shell, its WebView configuration and deep-link handling, and the native bridge.

No signing certificates, provisioning profiles or credentials are stored in this repository.
